HÁN NGỮ MỖI NGÀY · Web app học tiếng Trung HSK 1–3

CÁC TỆP TRONG GÓI
  index.html            Toàn bộ app (20 bài, nghe · đọc · nói · viết)
  sw.js                 Cho phép dùng khi không có mạng
  manifest.webmanifest  Tên, màu và biểu tượng khi cài lên điện thoại
  icons/                Biểu tượng app
  render.yaml           Cấu hình deploy lên Render

1. ĐƯA LÊN GITHUB
   - github.com > New repository > tên "hanngu-app" > Public > Create.
   - Bấm "uploading an existing file", kéo TẤT CẢ tệp BÊN TRONG
     thư mục này vào (không kéo cả thư mục) > Commit changes.
   - Nếu repo đã có tệp cũ: Add file > Upload files, kéo tất cả vào
     để ghi đè > Commit changes.

2. DEPLOY LÊN RENDER (làm 1 lần)
   - dashboard.render.com > New > Blueprint > chọn repo "hanngu-app" > Apply.
   - Hoặc: New > Static Site > chọn repo, Build Command để trống,
     Publish directory là "."
   - Sau khoảng 1 phút có link dạng https://hanngu.onrender.com
   - Mỗi lần cập nhật tệp trên GitHub, Render tự deploy lại.

3. CÀI LÊN ĐIỆN THOẠI
   - iPhone: mở link bằng Safari > nút Chia sẻ > "Thêm vào MH chính".
   - Android: mở link bằng Chrome > bấm nút "Cài đặt" trong app,
     hoặc menu ⋮ > "Cài đặt ứng dụng".

4. LƯU Ý
   - Mở app một lần khi có mạng, sau đó dùng được cả khi offline.
   - Giọng đọc lấy từ điện thoại: cần có giọng tiếng Trung.
   - Phần Nói: bấm vào ô, dùng micro trên bàn phím để đọc
     (nên thêm bàn phím tiếng Trung Giản thể).
